# Testing

## Layers

```
┌──────────────────────────────────────────────────────┐
│ Hand smoke (operator)                                │
│  ↑ catches: visual regressions, real-iPhone weirdness │
├──────────────────────────────────────────────────────┤
│ E2E with real iPhone (–tags=hardware)                │
│  ↑ catches: AFC quirks, deletion behavior            │
├──────────────────────────────────────────────────────┤
│ Integration with memory-backed AFC fake              │
│  ↑ catches: backup.Run() phase ordering, deletion-   │
│             after-skip behavior, error propagation   │
├──────────────────────────────────────────────────────┤
│ Unit tests (table-driven)                            │
│  ↑ catches: EXIF parsing, date precedence, name      │
│             suffix collision resolution              │
└──────────────────────────────────────────────────────┘
```

## What we test by hand

The GUI. Every release. Per [Hand-test the GUI](../runbooks/gui-smoke-test).

Visual regressions in the webview are not caught by Go tests. Whenever the frontend changes:
- Open it on macOS in maximized state.
- Verify no chrome bar element is buried under traffic lights.
- Walk through every tab.
- Plug iPhone in, watch the device card appear.
- Unplug iPhone, watch the device card clear within 2.5s.
- Run a small backup (5-10 files), verify summary.
- Repeat with delete-after, verify Photos.app exclamation-mark behavior matches what we describe in [AFC delete ghosts](../discoveries/afc-delete-ghosts).

## What we don't have yet

- **Headless GUI test.** Wails has a `playwright`-flavored hook but we haven't wired it.
- **CI smoke against a real iPhone.** No way to plug one into GitHub Actions; might shell into a Mac mini on Tailnet for this someday.
- **Mutation tests.** Out of scope pre-1.0.

## Running tests

```bash
# Unit + integration (no hardware)
go test ./...

# With hardware tests (requires iPhone connected)
go test -tags=hardware ./internal/afc/...

# With race detector
go test -race ./...

# Coverage
go test -coverprofile=cover.out ./...
go tool cover -html=cover.out
```

## Fixtures

`internal/exif/testdata/` carries small (~100 KB) sample files:
- `heic_with_exif.heic` — has EXIF DateTimeOriginal.
- `mov_with_moov.mov` — small MOV, parse the moov atom.
- `mp4_no_dates.mp4` — should fall back to mtime.
- `jpg_strict_exif.jpg` — well-formed.
- `corrupt.heic` — truncated, expect graceful zero.

Do NOT commit large fixtures. Anything >1 MB should be generated by a one-off helper invoked from the test, or pulled from a fixture bucket (not configured yet).

## Test data for the AFC fake

```go
fake := afctest.NewFake(map[string][]byte{
    "DCIM/100APPLE/IMG_0001.HEIC": heicWithExif,
    "DCIM/100APPLE/IMG_0001.MOV":  movPair,
    "DCIM/100APPLE/IMG_0002.HEIC": heicWithExif2,
})
res, err := backup.Run(ctx, backup.Options{Conn: fake, Output: tmpDir}, ignoreProgress)
```

The fake supports `Walk`, `PullTo`, `Remove`, `Stat`. It does NOT model partial writes / cancellation mid-read (separate suite for that).

## Known untested paths

- Multi-device disambiguation when two iPhones plugged in simultaneously.
- Windows-specific path separators in `--output`.
- Linux `usbmuxd` socket auth (we assume it just works).
- Long-running `--watch` mode (manual test only).
- Live Photos pairing under weird timezone changes.

All tracked in [GitHub Project 7](https://github.com/orgs/code-hartle-tech/projects/7).

## Pre-commit

There is no auto pre-commit hook (Lefthook / pre-commit not wired). Before committing:

```bash
gofmt -s -w ./...
go vet ./...
go test ./...
```

CI runs these on every PR.
